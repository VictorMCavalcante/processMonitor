# Monitor

App de barra de menus para macOS que mostra a pressão de memória, explica o que é cada processo (projeto, porta, há quanto tempo está aberto), aponta os esquecidos e deixa fechar com um clique. Nunca fecha nada sozinho.

- Testes: `scripts/test.sh`
- Gerar e instalar: `scripts/bundle.sh` (instala em `~/Applications/Monitor.app`)
- Design: `docs/superpowers/specs/2026-10-20-monitor-memoria-design.md`
