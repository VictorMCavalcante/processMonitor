# Marca Vernio

O nome vem de *vernier*, a escala do paquímetro que mede frações de milímetro: é monitoramento preciso e detalhado. O símbolo é uma linha de pulso (atividade) sobre uma régua (medida).

| Arquivo | Uso |
|---|---|
| `mark.svg` | símbolo sozinho (avatar, favicon) |
| `logo.svg` | símbolo + nome (README, site) |
| `icon.png` | ícone do app em 1024 px |
| `../../Resources/AppIcon.icns` | ícone do `.app`, gerado por `swift scripts/make-icon.swift` |

## Paleta

| Nome | Hex | Uso |
|---|---|---|
| Violeta | `#8B3DFF` | marca, controles do sistema (`Theme.brand`) |
| Lavanda | `#B48CFF` | gráficos, destaques (`Theme.accent`) |
| Névoa | `#D9C7FF` | detalhes (`Theme.mist`) |
| Noite | `#120E1A` | fundo (`Theme.bg`) |
| Painel | `#1C1726` | cards (`Theme.panel`) |
| Texto | `#F3EFFA` | texto (`Theme.text`) |

As cores de status (verde `#3DDC84`, âmbar `#FFB340`, vermelho `#FF5C5C`) não mudam: elas indicam a pressão de memória e os alertas.

O nome é escrito sempre em minúsculas no logotipo ("vernio") e com inicial maiúscula no texto ("Vernio").
